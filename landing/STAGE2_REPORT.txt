1) 승인 후 PR/CI 검토, 운영 git status clean·PREVIOUS_HEAD·변경 범위·운영 네트워크 4개/중복 0 확인. database/와 deploy/production-proxy 변경은 0이어야 합니다.

8. 롤백 — 준비만
빠른 화면 롤백: 외부에 백업한 기존 nginx.frontend.production.conf를 복원해 정적 정확 경로 5개를 제거한 뒤 프론트 nginx만 문법 검사·reload합니다. 기존 Flutter index는 바꾸지 않았으므로 / 접속 시 Flutter 첫 화면으로 돌아갑니다. DB·프록시는 건드리지 않습니다.
   cp "$BACKUP_DIR/nginx.frontend.production.conf" deploy/docker/nginx.frontend.production.conf
   docker exec tride-prod-frontend nginx -t
   docker exec tride-prod-frontend nginx -s reload
BACKUP_DIR은 승인된 배포 시 실제 생성하는 외부 백업 경로입니다. 아직 운영 백업 폴더를 만들거나 위 명령을 실행하지 않았습니다.
전체 코드 롤백이 필요하면 clean 여부와 외부 백업을 확인한 뒤 PREVIOUS_HEAD로 돌아가 백엔드·프론트만 --no-deps로 재빌드합니다. 스키마 롤백은 없습니다. APK·다운로드 파일은 변경하지 않습니다.

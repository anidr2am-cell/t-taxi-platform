# Golden baseline provenance

The privacy-policy (8 images) and contact LINE snackbar baseline were reviewed
and captured with Ubuntu / Flutter 3.41.6, the environment used by PR Checks.
Run `flutter test` in that environment for exact pixel comparisons; Windows
Flutter 3.41.9 is not the canonical image renderer.

Evidence: GitHub Actions run 36021700313 compared unchanged main `6ac6fce`
and admin PR head `b3eb433`. Both had the same 21 failures. All ten failing
actual images were byte-identical between the two revisions. Candidates were
generated by the targeted golden tests on the main revision and reviewed.

- Privacy: baseline predates the `0802acc` Markdown -> MarkdownBody/ListView
  change and added analytics section. The section-10 scroll capture now reaches
  a different offset because the document extends beyond the old scroll limit.
  The intended policy table remains present. Other differences include the
  pinned Linux engine's glyph edges. No policy or product styles were changed.
- Contact: snackbar/CTA geometry remains intact; the pinned Linux rendering is
  the baseline. The explicit floating-snackbar/CTA position assertions remain.
- Guest inquiry: do NOT accept the missing-icon failure image. The baseline is
  unchanged. The test now waits for both actual RawImage frames before capture,
  and fails if they never render (precache alone was insufficient under load).

The temporary pinned-ref comparison workflow was removed after collecting the
evidence: it deliberately re-runs known broken historical revisions and is not
a permanent PR gate. The existing PR Checks workflow is unchanged. No skips,
pixel tolerance changes, or required-check bypasses were introduced.

The square glyphs in these widget goldens are Flutter's test-font rendering,
not screenshots of production web fonts. Readable production typography and
locale rendering require browser QA separately.
